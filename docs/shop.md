# Tienda Online

## Descripción
Interfaz de cara al cliente para la visualización de productos y realización de pedidos.

## Estructura Actual
- Ubicación: `src/modules/shop/pages/ShopPage.tsx`

## Funcionalidades Clave
- Catálogo interactivo bimonetario.
- Selección de productos y carrito básico.

## Guía de Reestructuración / Mantenimiento
- El flujo de compra en la tienda debe integrarse con el módulo de `Ventas` para registrar pedidos de manera coherente.
- El diseño debe ser responsive y amigable.
